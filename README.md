## 📖 Overview

This project focuses on customer segmentation using clustering algorithms on an E-Commerce dataset. The objective is to identify groups of customers with similar purchasing behavior, enabling businesses to understand customer patterns, improve marketing strategies, and make data-driven decisions.

The project covers the complete machine learning workflow, including data preprocessing, exploratory data analysis, feature engineering, outlier treatment, feature scaling, clustering, and cluster evaluation.

---

## 🎯 Objectives

- Analyze customer purchasing behavior
- Create meaningful customer-level features
- Perform customer segmentation using clustering techniques
- Compare multiple clustering algorithms
- Extract actionable business insights

## 📂 Dataset Information

The dataset contains transactional records from an online retail business, including:

- Invoice Number
- Product Description
- Quantity Purchased
- Unit Price
- Customer ID
- Invoice Date
- Country

Customer-level features were created from the raw transactional data to perform clustering analysis effectively.

---

## ⚙️ Data Preprocessing

The following preprocessing techniques were applied:

- Missing value handling
- Duplicate record removal
- Feature engineering
- Outlier detection using IQR Method
- Min-Max Scaling
- Correlation Analysis
- Data Visualization

---

## 🤖 Clustering Algorithms

### 1. K-Means Clustering
- Implemented for customer segmentation
- Optimal number of clusters identified using the Elbow Method

### 2. Agglomerative Clustering
- Hierarchical clustering approach
- Used to compare clustering performance

### 3. DBSCAN
- Density-based clustering algorithm
- Effective in detecting noise and outliers
